# Seedream 5.0 Pro BytePlus Frontend

一个本地运行的 Seedream-5.0-pro 生图前端，支持文生图、单图/多参考图图生图，以及常用输出参数调整。界面针对手机和平板做了响应式适配；手机端以结果画布为主，参数收纳在底部抽屉中。默认跟随系统主题，也可手动切换浅色或深色模式。

## 启动

1. 复制 `.env.example` 为 `.env`，填入 `ARK_API_KEY`；如需使用其他模型，修改 `ARK_MODEL_ID`。
2. Linux 运行：

```bash
./start.sh
```

也可以直接使用 npm：

```bash
npm start
```

3. 打开终端输出里的本地地址，默认是 `http://127.0.0.1:8787`。

也可以不写 `.env`，直接在页面里临时输入 BytePlus API Key。

### 局域网访问

默认仅允许本机访问。如需让同一局域网中的手机、平板或其他电脑使用，在 `.env` 中设置：

```dotenv
HOST=0.0.0.0
PORT=8787
```

重启后，终端会列出本机和局域网访问地址；其他设备打开 `http://<服务器局域网 IP>:8787` 即可。若无法访问，请确认 Linux 防火墙已放行对应端口。监听 `0.0.0.0` 会将服务暴露给所有可连接到该端口的设备，请仅在可信局域网中使用，不要直接暴露到公网。

生成期间，结果网格中会显示带提示词、已耗时和取消按钮的任务卡片。可以连续提交多个并发任务，完成后各任务卡片会原位替换为新图片，并保留之前的结果。点击结果图片可在站内全屏预览，并可通过 Esc、遮罩或关闭按钮返回。

### 自动保存与提示词记录

默认会把生成图片保存到项目的 `generated` 目录。以下配置可控制保存行为和保存位置：

```dotenv
AUTO_SAVE_IMAGES=true
SAVE_PROMPT_METADATA=false
OUTPUT_DIR=generated
```

- `AUTO_SAVE_IMAGES`：是否在生图完成后自动保存图片，默认 `true`
- `SAVE_PROMPT_METADATA`：是否为每张已保存图片生成同名 `.txt` 文档，默认 `false`
- `OUTPUT_DIR`：图片和提示词参数文档的保存目录，默认 `generated`

提示词参数文档会记录提示词、模型、尺寸、生成模式、输出/返回格式、水印、参考图摘要、接口地址和高级参数。例如图片名为 `seedream-20260721-120000-1-ab12cd34.png` 时，记录文件名为 `seedream-20260721-120000-1-ab12cd34.txt`。本地参考图的数据内容和 API Key 等常见敏感参数不会写入文档。

`SAVE_PROMPT_METADATA=true` 依赖 `AUTO_SAVE_IMAGES=true`。如果关闭图片自动保存却开启提示词参数记录，服务会拒绝启动并提示修正配置。修改这些配置后需重启服务。

## 后端日志

后端日志使用操作系统本地时区，时间精确到秒，并在同一次请求的日志中保留相同的 8 位请求 ID。保存图片的文件名也使用简洁的本地时间，例如 `seedream-20260715-023000-1-ab12cd34.png`。通过 `.env` 中的 `LOG_LEVEL` 控制输出量：

- `debug`：输出 HTTP 请求、BytePlus 上游调用、图片保存详情和任务心跳，适合排查问题
- `info`：默认级别；用中文自然语言输出服务启动和生成开始/结果，同时保留警告和错误
- `warn`：只输出警告和错误
- `error`：只输出错误
- `silent`：关闭全部日志

修改日志配置后需重启服务生效。生成任务活跃时，`debug` 级别默认每 10 秒输出一次状态心跳；可用 `STATUS_LOG_INTERVAL_MS` 调整间隔，设为 `0` 可彻底关闭心跳。`/api/health` 会返回当前日志级别、自动保存配置、监听地址、访问地址、请求数、生成统计和活跃任务阶段。

## 支持参数

- 模型：通过 `.env` 中的 `ARK_MODEL_ID` 配置，默认 `dola-seedream-5-0-pro-260628`
- 区域/Base URL：`ap-southeast-1`、`eu-west-1` 或自定义
- 模式：文生图、图生图
- 任务：支持并发生成和逐任务取消
- 参考图：图片 URL 或本地图片转 data URL，最多 10 张
- 尺寸：自动、按 `1K`/`2K` 与所选比例使用文档中的精确 `widthxheight`，或自定义像素尺寸；图生图新增参考图后会自动选择最接近的预设比例
- 输出：`png`、`jpeg`
- 返回：`url`、`b64_json`
- 自动保存：支持 URL 和 Base64 返回，可通过 `.env` 开关；还可为每张图片保存同名提示词参数文档
- 水印：开/关
- 高级 JSON：用于透传文档新增参数，核心字段会由界面设置覆盖

> 如果你的 BytePlus 账号或接口策略不接受 data URL 形式的本地图片，请改用可访问的图片 URL。
